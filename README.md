# 人生窗口期 · Life Windows

一个以年龄为坐标、区分硬窗口、制度窗口、黄金窗口、社会常见阶段与长期开放事项的人生机会窗口可视化 MVP。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:4173/`

## 质量检查

```bash
npm run test
npm run lint
npm run build
```

## 页面

- `/`：年龄 Slider、动态摘要、分类与人生时间轴
- `/now`：当前仍开放或仍然可做的窗口
- `/window/:slug`：窗口档案、依据与不同目标模型
- `/ask`：基于本地数据的“我还来得及吗？”模拟问答

## 数据说明

当前包含 36 条用于验证产品与界面的示例数据，六个分类各 6 条。数据中会明确区分社会常见年龄与真实限制；所有编辑数据都保留证据等级和来源说明字段，不能作为个体结论使用。
